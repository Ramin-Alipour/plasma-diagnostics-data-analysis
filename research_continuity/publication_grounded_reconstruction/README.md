# Publication-Grounded Reconstruction

This is the 2026 bridge between historical experimental publications and current reproducible computational practice.

Six peer-reviewed IR-T1 papers provide quantitative constraints. Each case uses the most defensible available evidence hierarchy:

**exact table value → exact reported value/range → paper equation/model → calibrated figure digitization where worthwhile → explicit synthetic/model assumption**

The output remains labelled synthetic/model-constrained whenever raw data are unavailable.
