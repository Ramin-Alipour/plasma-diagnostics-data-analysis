# Post-2018 Scientific & Technical Work

## Scope

From 2018 onward, the public repository represents the transferable computational and scientific-analysis side of independent scientific/technical work rather than claiming access to confidential client datasets.

### Activity areas

- Quantitative scientific data analysis
- Python/MATLAB-based analysis workflows
- Signal processing and time-series analysis
- Spectral and frequency-domain analysis
- Scientific data interpretation
- Historical materials-characterization data analysis including XRD/SEM/AFM/XPS/TEM-oriented work; corresponding workflows are not implemented or demonstrated in this repository
- Technical R&D support and reproducible computational methods

## Public-evidence policy

Client/project-specific datasets, proprietary reports, and confidential technical files are not included. The repository instead provides representative, non-confidential methodology through publication-grounded reconstruction and synthetic computational consistency checks.

> Client/project-specific datasets are not included due to confidentiality; representative methodology is demonstrated using publication-grounded datasets.

This statement is intentionally narrower than a claim of continuous experimental plasma operation. The public evidence demonstrates continuity of scientific and computational practice while preserving the distinction between historical experimental work, independent technical work, and current reproducible reconstruction.
