# Dataset A / Dataset B provenance and quality-control note

**Status: source categories are distinct; some values can legitimately coincide.**

Dataset A contains the owner's supplied laboratory/device/software records. Dataset B contains values transcribed or reconstructed from the six cited IR-T1 publications. Dataset B is **not a synthetic-noise version** of Dataset A. Synthetic measurements generated by the Python reconstruction functions are a third category and must remain labelled synthetic.

## E02 / P02 modal table

The 20 rows in `datasets/dataset_a/laboratory_measurements/exp2_modes.csv` coincide numerically with the values printed in Table 2 of P02, transcribed in `datasets/dataset_b/publication_reconstruction/paper2_modes.csv`. This is consistent with the possibility that Dataset A contains the original values underlying the publication and Dataset B transcribes those same published values. It is **not evidence that either file is synthetic**, and the values must not be altered to manufacture a difference.

The two files have different provenance roles:
- Dataset A: owner-supplied laboratory/device/software record.
- Dataset B: publication transcription from P02, Table 2.
- Because the numerical content overlaps, this pair is not an independent validation dataset or an independent comparison.

The P02 table values are printed to three decimal places in the source. Preserve the published values and their printed precision; do not normalize modal percentages.

Preserve both values and their different provenance; do not overwrite Dataset A or force a match. This is a documented source/data discrepancy requiring interpretation, not a value to conceal. The Results text also reports maximum currents of about 20/22/22 kA and steady-state times of 12/11/10 ms; these are text-reported values (the current values are approximate), not figure estimates.

## P05 limiter/bias effects — re-extracted from Results and Conclusion

The P05 table was checked against the full article text. Two earlier qualitative encodings were corrected: at 10 mm, Reynolds stress is reported to have wild fluctuations and a dramatic increment under the applied voltages (not a reduction); at 5 mm with −200 V, the paper says the bias was not effective in decreasing radial transport, not that a specific increase was measured. The re-extracted table also keeps the conclusion-level ranges distinct from the narrower figure/result statements: radial electric field +20–30%, poloidal electric field −30–40%, poloidal turbulent transport +25–35%, radial turbulent transport −35–45%, and Reynolds stress −5–10% for the 5 mm, +200 V case. These are reported effects, not new measurements or independent validation.

## E06 / P06 figure comparison

The owner reports that `datasets/dataset_a/laboratory_signal_analysis/e06_mhd_signal.csv` came from the diagnostic software. The file has 423 rows and columns including `x_pixel`, `y_pixel`, `frequency_kHz`, and `amplitude`; that structure does not establish that it is a raw time-domain waveform. A possible acquisition/export/processing issue is a hypothesis to investigate, not a verified explanation. Its values remain unchanged until the original export, acquisition metadata, or other traceable evidence can resolve the issue.

The separate P06 Figure 2 dataset is publication digitization. Numerical similarity alone does not prove that E06 was digitized from the paper, and the owner's source declaration alone does not provide independent acquisition-log verification. Keep this uncertainty explicit; do not calculate a time-domain PSD from E06 as currently structured.

## Required extraction and reporting rules

- Dataset B table values must follow the cited paper's actual text/table values and retain source precision.
- For figure-derived values, document the figure, axes calibration, digitization method, and uncertainty. Decimal places must not be presented as accuracy unsupported by source resolution.
- Do not add synthetic noise to the publication-reference tables, alter source values to force agreement, or treat overlapping Dataset A/B values as independent experimental validation.
- This note records the owner's source declaration and the current file-level audit; it does not claim independent access to the diagnostic software or acquisition logs.
