# Historical publication-reconstruction tables

These CSV files are preserved byte-for-byte from the former top-level `data/publication_reconstruction/` directory for audit traceability only. They are **superseded snapshots and are not the current Dataset B**. Their values and schemas differ from the source-rechecked canonical files.

Use only the current, provenance-manifested files under `datasets/dataset_b/publication_reconstruction/`. In particular, do not use these archived copies for analysis, figures, the manuscript, or current A/B comparison.

The canonical Dataset B files are covered by `datasets/dataset_b/source_manifest.csv` and the automated exact-byte integrity test. The archived snapshots are retained to make the historical transition inspectable, not to provide alternate current data.
