Please consider the manuscript “Plasma Diagnostics Data Analysis: Reproducible Python Workflows for Spectroscopy, Magnetic Fluctuations, X-Ray Signals, and Electrostatic-Probe Analysis” as an Original Software Publication in SoftwareX.

The manuscript describes an open-source Python package that organizes reusable analysis workflows for optical spectroscopy, hard X-ray signals, magnetic fluctuations, electrostatic probes, and turbulence- and transport-related analysis. It combines diagnostic-specific modules with shared signal-processing utilities, executable notebooks, automated tests, and machine-readable provenance records. Six computational case studies grounded in published IR-T1 tokamak studies illustrate the workflows.

The manuscript distinguishes the repository’s data sources explicitly: Dataset A contains real supplied raw laboratory measurements and diagnostic device/software outputs, including the E06 diagnostic-software output; Dataset B contains data extracted from or reconstructed using published papers; and synthetic inputs are separately labelled for selected demonstrations and tests. The repository does not include a complete archive of original IR-T1 tokamak shots. That archive limitation does not mean the repository lacks real laboratory data. Publication-reconstruction cases are computational demonstrations and consistency checks, not recovered experimental discharges or independent experimental validation.

The software described in the manuscript is the published v0.2.2 release, available under the MIT license at https://github.com/Ramin-Alipour/plasma-diagnostics-data-analysis/releases/tag/v0.2.2 and archived with version-specific DOI https://doi.org/10.5281/zenodo.23300661.

We believe the package may be useful to researchers seeking inspectable, adaptable starting points for analysis of heterogeneous plasma-diagnostic data. The manuscript makes no claim of external adoption or performance improvements beyond the documented software tests and demonstrations.
