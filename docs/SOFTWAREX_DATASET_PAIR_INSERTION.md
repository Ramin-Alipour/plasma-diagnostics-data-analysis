# SoftwareX manuscript update: paired dataset-generation workflow

## Insert in Section 2 (Software description)

A paired-dataset utility, `publication_reconstruction.dataset_pair`, converts numeric entries in the machine-readable provenance register into a normalized reference table and a linked synthetic perturbation table. Each reference row retains the paper identifier, source locator, quantity, unit, source type, and extraction method. The synthetic table preserves the reference value and records the perturbation realization, relative-noise standard deviation, random seed, and zero-value handling. For non-zero reference values, the generator applies multiplicative Gaussian noise, \(x_B=x_A(1+\epsilon)\), with \(\epsilon\sim\mathcal{N}(0,0.013^2)\). Exact zeros are preserved and explicitly flagged because relative noise is undefined at zero. The output metadata file records row counts, the seed, and the noise model.

The 0.1% value used in the workflow is a target for numerical extraction precision, not a claim that digitized values reproduce the underlying measurement to 0.1% accuracy. The resulting paired tables support deterministic software tests and controlled sensitivity analysis; they do not recover missing acquisition arrays.

## Insert in Section 4 (Reuse, limitations, and future development)

To regenerate the paired tables from the provenance register, run:

```bash
python -m publication_reconstruction.dataset_pair \
  --provenance plasma_provenance/records.json \
  --output-dir data/paired_publication_reconstruction \
  --seed 20261011
```

The command writes `dataset_A_publication_reference_values.csv`, `dataset_B_synthetic_1p3pct.csv`, and `dataset_pair_metadata.json`. The seed makes the synthetic realization reproducible. Non-numeric reported values are excluded from the numeric tables and counted in metadata rather than coerced to zero.

## Data-availability wording

The repository provides publication-derived reference values, their provenance metadata, and synthetic perturbations generated by a documented procedure. Original IR-T1 instrument-acquisition arrays are not included in the public repository. Publication-derived values and synthetic perturbations should not be described as verified original instrument records without independent acquisition-file evidence.
